# Spatial Partition Pattern

## Overview
Organizes spatial objects for efficient querying.

## Structure
```
spatial-partition/
├── build.gradle.kts
├── README.md
└── src/main/java/com/javastarterkit/patterns/spatialpartition/
    └── SpatialPartition.java
```

## Implementation
The Spatial Partition pattern is implemented as a single self-contained Java file with:
- Inner static classes/interfaces that implement the pattern
- A `demonstrate()` method that runs the pattern example
- A `main()` method that calls `demonstrate()`

## Usage
```bash
# Build the pattern
./gradlew :system-design-pattern:structural:spatial-partition:build

# Run the pattern example
./gradlew :system-design-pattern:structural:spatial-partition:run
```
