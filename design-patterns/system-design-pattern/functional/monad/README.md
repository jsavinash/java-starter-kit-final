# Monad Pattern

## Overview
Wraps values and provides composition operations.

## Structure
```
monad/
├── build.gradle.kts
├── README.md
└── src/main/java/com/javastarterkit/patterns/monad/
    └── Monad.java
```

## Implementation
The Monad pattern is implemented as a single self-contained Java file with:
- Inner static classes/interfaces that implement the pattern
- A `demonstrate()` method that runs the pattern example
- A `main()` method that calls `demonstrate()`

## Usage
```bash
# Build the pattern
./gradlew :system-design-pattern:functional:monad:build

# Run the pattern example
./gradlew :system-design-pattern:functional:monad:run
```
