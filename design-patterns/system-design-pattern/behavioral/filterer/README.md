# Filterer Pattern

## Overview
Filters collections based on criteria.

## Structure
```
filterer/
├── build.gradle.kts
├── README.md
└── src/main/java/com/javastarterkit/patterns/filterer/
    └── Filterer.java
```

## Implementation
The Filterer pattern is implemented as a single self-contained Java file with:
- Inner static classes/interfaces that implement the pattern
- A `demonstrate()` method that runs the pattern example
- A `main()` method that calls `demonstrate()`

## Usage
```bash
# Build the pattern
./gradlew :system-design-pattern:behavioral:filterer:build

# Run the pattern example
./gradlew :system-design-pattern:behavioral:filterer:run
```
