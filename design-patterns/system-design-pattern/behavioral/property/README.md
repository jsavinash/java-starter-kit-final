# Property Pattern

## Overview
Manages dynamic properties on objects.

## Structure
```
property/
├── build.gradle.kts
├── README.md
└── src/main/java/com/javastarterkit/patterns/property/
    └── Property.java
```

## Implementation
The Property pattern is implemented as a single self-contained Java file with:
- Inner static classes/interfaces that implement the pattern
- A `demonstrate()` method that runs the pattern example
- A `main()` method that calls `demonstrate()`

## Usage
```bash
# Build the pattern
./gradlew :system-design-pattern:behavioral:property:build

# Run the pattern example
./gradlew :system-design-pattern:behavioral:property:run
```
