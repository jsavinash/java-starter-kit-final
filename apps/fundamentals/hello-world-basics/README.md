# Hello World Basics — Spring Boot Study Material

A minimal Spring Boot application for absolute beginners to understand the framework's fundamentals.

## 🎯 Purpose

The simplest possible Spring Boot application — a "Hello World" REST endpoint.

## 🚀 How to Run

```bash
./gradlew :apps:fundamentals:hello-world-basics:bootRun
```

## 📚 Concepts Demonstrated

- `@SpringBootApplication` annotation
- `@RestController` and `@GetMapping`
- Spring Boot's embedded Tomcat server
- Application entry point (`main` method)
