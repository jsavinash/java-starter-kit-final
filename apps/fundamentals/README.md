# Spring Boot Fundamentals

Core Spring Boot concepts including IoC containers, REST APIs, auto-configuration, monitoring, and development tools.

## Projects

| Project | Description |
|---------|-------------|
| [**webapp**](./webapp/) | Basic Spring Boot web application demonstrating convention plugins and platform BOM |
| [**ioc-example**](./ioc-example/) | Inversion of Control — dependency injection, bean scopes, lifecycle callbacks, component scanning |
| [**hello-world-basics**](./hello-world-basics/) | Minimal Spring Boot starter application for newcomers |
| [**spring-boot-rest**](./spring-boot-rest/) | REST API development with controllers, validation, exception handling, and DTOs |
| [**actuator-devtools**](./actuator-devtools/) | Production-ready features — Actuator monitoring endpoints, custom health indicators, DevTools |
| [**starters-autoconfig**](./starters-autoconfig/) | Spring Boot starters and auto-configuration with `@Conditional` annotations |
| [**greeting-service**](./greeting-service/) | Custom auto-configuration library with `@Enable*` annotation |
| [**spring-boot-devtools**](./spring-boot-devtools/) | Developer tools — automatic restart, LiveReload, development-time optimizations |
| [**spring-petclinic**](./spring-petclinic/) | Classic PetClinic reference application with Thymeleaf, JPA, and H2 |
| [**spring-aot**](./spring-aot/) | Ahead-of-Time (AOT) compilation and GraalVM native image support |
| [**spring-framework-loaded**](./spring-framework-loaded/) | Spring Loaded — runtime class reloading and hot swapping |

## Concepts Covered

- Dependency Injection & IoC
- RESTful Web Services
- Auto-configuration & Starters
- Actuator & Production Monitoring
- Developer Tools & LiveReload
- AOT Compilation & Native Images
- Thymeleaf Templating
