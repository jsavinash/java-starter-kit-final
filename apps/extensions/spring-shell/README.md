# Spring Shell — Interactive CLI Application Example

Demonstrates building interactive command-line applications with Spring Shell.

## 🎯 Purpose

Shows how to create CLI applications with Spring Shell, including command definitions, parameter binding, and custom shell prompts.

## 🧩 Key Dependencies

- `spring-shell-starter` — Spring Shell framework

## 🚀 How to Run

```bash
./gradlew :apps:extensions:spring-shell:bootRun
```

## 📚 Concepts Demonstrated

- **@ShellMethod** — Command definition annotation
- **@ShellOption** — Command parameter binding
- **Shell Prompt** — Customizable shell prompt
- **Command Groups** — Organize commands by category
- **Input Conversion** — Type conversion for command parameters
- **Command Completion** — Tab completion for shell commands
- **Interactive Commands** — Read-eval-print loop (REPL)
