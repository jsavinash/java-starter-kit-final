# Spring AI — AI/ML Integration Example

Demonstrates Spring AI for integrating AI/ML capabilities into Spring Boot applications.

## 🎯 Purpose

Shows how to build AI-powered applications with Spring AI, including LLM interactions, vector databases, and AI workflows.

## 🧩 Key Dependencies

- `spring-ai` — Spring AI framework

## 🚀 How to Run

```bash
./gradlew :apps:extensions:spring-ai:bootRun
```

## 📚 Concepts Demonstrated

- **LLM Integration** — Interact with OpenAI, Anthropic, Ollama models
- **Prompt Engineering** — Structured prompt templates
- **Vector Databases** — Store and query embeddings
- **Document Processing** — Load, transform, and analyze documents
- **AI Workflows** — Chain AI operations with business logic
- **Output Parsing** — Structured output from LLM responses
- **Retrieval Augmented Generation (RAG)** — Context-aware AI responses
