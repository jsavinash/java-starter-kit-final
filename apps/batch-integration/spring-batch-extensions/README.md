# Spring Batch Extensions — Extended Batch Processing Example

Demonstrates extended Spring Batch capabilities including async processing and administrative tools.

## 🎯 Purpose

Shows advanced batch processing features beyond core Spring Batch, including async job processing and administrative extensions.

## 🧩 Key Dependencies

- `spring-boot-starter-batch` — Spring Batch framework
- `spring-batch-extensions` — Extended batch capabilities
- `h2` — In-memory H2 database

## 🚀 How to Run

```bash
./gradlew :apps:batch-integration:spring-batch-extensions:bootRun
```

## 📚 Concepts Demonstrated

- **Async Job Processing** — Non-blocking job execution
- **Batch Administration** — Job monitoring and management
- **Extended Job Repository** — Additional storage options
- **Job Operator** — Programmatic job control
- **Job Explorer** — Query job execution history
- **Partitioning** — Parallel processing across partitions
